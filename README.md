# LEADS Website Prototype

An interactive website for comparing LEADS classes and helping students identify the class that best fits their interests and goals.

## About the Project

I am developing this project while training to become a LEADS Ambassador at UNC Charlotte. The website will use interactive Venn diagrams to show:

- Activities that are unique to each LEADS class
- Skills and experiences that multiple classes share
- A class-matching form that helps students identify an appropriate course

## Project Goals

- Make LEADS course information easier to understand
- Help students compare classes visually
- Practice accessible and responsive web design
- Document the process of building and publishing a website with GitHub
- Strengthen my front-end development and version-control skills

## Technologies

This project will use:

- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages

## Development Status

This project is currently in the prototype and research stage. Class information and activities will be verified before the website is presented as an official LEADS resource.
